# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Send a private report to `security@benefitsi.com` with:

- a concise description of the issue;
- affected pages, API routes, or components;
- reproducible steps or a minimal proof of concept;
- the potential impact; and
- suggested remediation, if available.

Do not include real customer, partner, employee, payment, or authentication data.

## Secrets

Never commit credentials, access tokens, private keys, production environment values, or exported customer data. Revoke and rotate any credential immediately if it may have been exposed.
